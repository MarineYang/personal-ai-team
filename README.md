# 팀룸 — 나에게 맞는 AI 전문팀

디렉터와 먼저 이야기하고, 필요한 전문가들을 구성하는 개인용 AI 사무실입니다. 공유받은 사용자는 본인의 컴퓨터와 Codex 로그인으로 독립적인 팀을 운영합니다.

## 처음 실행하기

1. [Node.js](https://nodejs.org/) 24 이상과 [Git](https://git-scm.com/)을 설치합니다.
2. 아래 명령으로 저장소를 내려받습니다.

```sh
git clone https://github.com/MarineYang/personal-ai-team.git
cd personal-ai-team
```

3. Codex CLI를 설치하고 본인 계정으로 로그인한 뒤 팀룸을 실행합니다.

```sh
npm install -g @openai/codex
codex login
npm run setup
npm run launch
```

이미 Codex가 설치되어 있다면 첫 번째 명령은 생략합니다. 로그인은 각자의 계정으로 직접 완료합니다. 이 앱은 Codex app-server에서 ChatGPT 로그인으로 확인되는 계정을 사용하며, 이용 가능 여부와 한도는 계정에 따릅니다. API 키 과금으로 자동 전환하지 않습니다. 설치·로그인 방법은 [OpenAI 공식 CLI 안내](https://learn.chatgpt.com/docs/codex/cli)를 참고하세요.

`npm run setup`은 의존성 설치, 화면 빌드, 환경 점검을 수행합니다. 계정 인증정보를 복사하거나 프로젝트에 저장하지 않습니다.

### 운영체제별 실행

| 환경 | 실행 방법 | 확인 범위 |
| --- | --- | --- |
| macOS | 최초 설정 후 `팀 실행.command` 더블클릭 또는 `npm run launch` | 실제 개발·실행 검증 환경 |
| Linux | `sh start.sh` 또는 `npm run launch` | POSIX 실행 경로 제공, 실기기 미검증 |
| Windows | WSL2의 Linux 환경에 Node·Codex를 설치하고 위 Linux 명령 사용 | WSL 실행 경로 제공, 실기기 미검증 |

Windows 네이티브 실행은 이 배포본의 검증 대상이 아닙니다. WSL에서 브라우저가 자동으로 열리지 않으면 Windows 브라우저에서 터미널에 나온 주소를 여세요.

기본 주소는 **http://127.0.0.1:18940** 입니다. 서버 터미널을 유지하고, 종료할 때 `Ctrl+C`를 누릅니다. 이미 같은 포트에서 팀룸이 실행 중이면 새 서버 대신 기존 화면을 엽니다.

다른 포트가 필요하면:

```sh
PORT=18941 npm run launch
```

## 사용 흐름

1. **디렉터와 상담:** 어떤 팀이 필요한지 이야기합니다. 처음에는 디렉터 한 명뿐입니다.
2. **구성안 검토:** 목표·범위·제약을 논의한 뒤 분야에 맞는 전문가 2~4명을 제안받습니다. 역할과 담당 결과물을 수정할 수 있습니다.
3. **팀 구성 확정:** `이 구성으로 팀 만들기`를 누르면 전문가들이 생성됩니다.
4. **합류 연출:** 면접→합류 확정→자리 세팅과 함께 캐릭터들이 등장합니다. 실제 작업 진행률은 팀원 카드에 표시합니다.
5. **아이디어 판단:** 조사 전문가와 디렉터가 근거·반대 의견·대안을 검토합니다. 중요한 선택이 있으면 반문하고 답변을 기다립니다.
6. **제작·검수:** 방향이 정해지면 전문가가 작업하고 디렉터가 결과를 간단히 정리합니다.

화면에는 디렉터와의 대화, 결정 사항, 필요한 사용자 행동, 결과물이 표시됩니다. 팀 내부 대화와 도구 로그는 기본 화면에 노출하지 않습니다.

## 현재 가능한 범위

- 프로젝트별 전문가 구성, 조사·기획·문서 제작·검수
- Three.js 사무실, 입사 애니메이션, 실시간 작업 상태
- Markdown 산출물 저장·열람·다운로드
- 방향 확인 대기와 팀 구성안의 재시작 후 복원

**촬영본 업로드→영상 편집→완성 영상 출력 파이프라인은 아직 구현되지 않았습니다.** 팀의 역할을 영상 편집자로 정하는 것만으로 편집 기능이 추가되지는 않습니다. 실제 사용 가능한 도구 범위는 실행 환경에 따릅니다.

## 데이터와 계정

각자의 프로젝트 폴더 안에 별도로 저장됩니다.

- `.runtime/state.json`: 상담·팀 상태·운영 기록
- `workspace/artifacts/`: 저장한 결과물
- Codex 로그인: 해당 사용자의 Codex 인증 저장소에서 관리

AI 추론은 연결된 서비스에서 수행됩니다. 로컬 실행은 오프라인 AI를 뜻하지 않습니다. 같은 OS 계정과 같은 폴더를 함께 사용하면 데이터도 공유되므로, 사람마다 별도의 계정과 설치 폴더를 사용하세요.

이 배포본은 **각자 설치하는 로컬 앱**입니다. 여러 사람이 웹 주소로 접속하는 공개 서비스용 로그인·사용자별 데이터 격리·운영 과금 기능은 포함하지 않습니다. 서버는 루프백 주소에만 연결됩니다.

## 문제 해결

```sh
npm run doctor
codex login status
```

- Node가 없거나 버전이 낮음: Node.js 24 이상 설치 후 터미널 재실행.
- Codex를 찾지 못함: CLI를 설치하고 새 터미널에서 `codex --version` 확인.
- 로그인·사용 한도 오류: 본인 계정의 Codex 로그인과 이용 가능 여부 확인.
- 포트 사용 중: 기존 팀룸을 종료하거나 다른 `PORT` 지정.
- 브라우저가 열리지 않음: 터미널의 로컬 주소를 직접 열기.
- WebGL 사용 불가: 3D 대신 상태 카드와 상담·결과물 기능 사용 가능.
- 업데이트 적용: 서버 종료 후 새 코드를 적용하고 `npm run setup`, `npm run launch` 실행. 기존 `.runtime/`, `workspace/`는 보존.

## 개발과 업데이트

```sh
npm ci
npm run build
npm run check
npm test
npm run release
```

GitHub 저장소를 공유하면 다른 사람도 위 설치 절차로 사용할 수 있습니다. 업데이트할 때는 서버를 종료한 뒤 `git pull`, `npm run setup`을 실행하고 다시 시작하세요. 로컬 코드 수정이 있다면 먼저 커밋하거나 보관하세요. 대화·결과물은 Git 추적에서 제외되어 유지됩니다.

ZIP이 필요한 경우에만 `npm run release`를 사용합니다. ZIP 생성에만 Python 3이 필요하며, GitHub 설치와 일반 실행에는 필요하지 않습니다. `dist/teamroom-0.2.0.zip`을 공유하세요. 배포 스크립트는 명시적으로 지정한 코드·안내 파일만 포함합니다. 기존 대화·결과물·로그인·환경 파일·node_modules는 포함하지 않습니다. 프로젝트 전체 폴더를 직접 압축하지 말고 이 명령으로 배포본을 만드세요.

- `public/dashboard.js`: 상담·구성안·브리핑 UI
- `public/office.js`: 3D 사무실
- `lib/roles.mjs`: 디렉터 지침과 전문가 지침 생성
- `server.mjs`: 상담·생성·작업 순서 및 Codex 연결

운영 중인 서버의 읽기 전용 확인: `npm run smoke`. 모델 작업은 제출하지 않습니다. `npm test`는 실제 모델 호출 없이 서버 동작을 검증합니다.
