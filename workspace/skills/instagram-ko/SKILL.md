# 한국어 Instagram 제작·분석

목표는 한국어로 실제 말할 수 있는 대본과 검증 가능한 개선안을 만드는 것이다. 점수를 성장 예측으로 제시하지 않는다. 계정 접속·수집·게시 기능이 내장된 스킬은 아니다.

## 작업 시작

- 요청이 포지셔닝, 참고 계정 분석, 대본, 성과 분석 중 무엇인지 구분하고 필요한 작업만 한다.
- 이미 알려진 상황·말투·타깃을 활용한다. 말투 기록이 있으면 읽는다. 처음부터 긴 설문을 요구하지 않는다.
- 다른 사람이 재사용할 스킬에 개인 사정을 기본값으로 넣지 않는다. 개인 설정에는 [말투 양식](assets/voice-template.md)을 쓴다.
- 목표 시청자의 언어·관심·수준을 먼저 고려한다. 한국어 콘텐츠라는 이유로 한국인의 취향을 단정하지 않는다.

## 대본 만들기

1. 실제 사건, 시청자에게 연결되는 감정, 이번 편의 작은 결과를 찾는다. 경험하지 않은 실패나 성과를 만들어 감정을 유도하지 않는다.
2. 필요하면 훅 2~3개를 서로 다른 접근으로 제안한다. 상황의 모순, 궁금한 결과, 작은 변화 등에서 선택한다. 숫자·부정어·과장을 억지로 넣지 않는다.
3. 훅의 평가는 '상황 이해 가능성 / 다음 장면이 궁금한 이유 / 실제 경험의 근거 / 화면으로 보여줄 수 있는가'로 설명한다. 100점 점수, 바이럴 확률, AI 작성 여부 판정은 하지 않는다.
4. 요청 길이에 맞춰 `장면 / 직접 말할 문장 / 화면 자막 / 필요한 촬영`을 작성한다. 간단한 요청에는 표를 강요하지 않는다.
5. 말투와 호흡을 확인한다. 자막은 낭독문을 그대로 복제하기보다 필요한 정보를 보충한다. 존댓말·반말을 설정 없이 오가지 않는다. 과도한 조사 생략, 번역투, 억지 밈을 피한다.
6. 시간은 녹음으로 확인한다. 한국어·일본어에 영어 단어 수와 WPM을 적용하지 않는다. 타임코드는 편집 목표로 표시하고 실제 발화 시간처럼 제시하지 않는다. 개인 낭독 샘플이 있을 때만 동일한 계산 단위로 보정한다.

휴식·실패가 있는 챌린지도 연속된 이야기로 구성할 수 있다. 챌린지 날짜와 업로드 횟수를 구분한다. 처음과 나중의 비교는 조건 차이도 설명한다.

## 참고 계정과 성과 분석

이 작업에서는 [분석 지침](references/analysis.md)을 읽는다. 접근할 수 없는 영상은 본 것처럼 설명하지 않는다. 사실·창작자의 주장·분석자의 해석을 구분한다.

## 여러 플랫폼에 적용

- Instagram·TikTok·Shorts는 동일한 촬영 원본에서 시작할 수 있다. 플랫폼별 성격을 고정관념으로 정하지 말고, 필요할 때 첫 장면·제목·자막 위치를 시험한다.
- Threads는 같은 경험에서 독립적으로 읽히는 관찰이나 고민을 쓴다. 매번 질문·외부 링크·참여 요청으로 끝내지 않는다.
- 변경한 가설, 바꾼 요소, 확인할 지표를 기록한다. 서로 다른 플랫폼의 조회수만으로 편집 효과를 입증했다고 하지 않는다.
- 음악 사용 범위, 표시 영역, 게시 제한, 광고 표기 등 변동하는 사항은 필요한 시점에 공식 자료로 확인한다. 원본 스킬의 수치·정책을 고정 상수로 복사하지 않는다.

## 결과 전달

바로 사용할 결과물을 먼저 준다. 실제 자료가 없으면 기획안 또는 검증 전 가설이라고 명시한다. 제작 요청에는 다음 촬영 행동을, 분석 요청에는 근거와 다음 실험을 덧붙인다. 요청하지 않은 게시·댓글·DM 발송은 하지 않는다.
