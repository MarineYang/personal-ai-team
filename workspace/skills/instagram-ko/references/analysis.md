# 참고 영상 및 게시 후 분석

## 접근 가능한 근거부터 확인

사용자가 지정한 계정과 게시물을 우선한다. 공개 페이지, 사용자가 제공한 영상·캡션·인사이트, 현재 사용할 수 있는 읽기 도구를 이용한다. 로그인이 필요하면 사용자에게 직접 로그인을 맡긴다. 접근 불가 시 무엇이 부족한지 밝히고 확인 가능한 범위로 진행한다.

프로필 텍스트만 읽었으면 정체성과 소개 문구만 평가한다. 컷 전환·표정·오디오·훅 연출은 영상을 확인한 경우에만 평가한다. 외부 수집 서비스의 수치는 수집 시점과 출처를 붙이고 실시간 수치로 부르지 않는다.

## 수집 항목

목적에 필요한 항목만 기록한다:

- 계정, 원본 URL, 게시일, 확인일, 플랫폼
- 영상 길이, 시작 문구, 첫 화면, 주요 전개와 결말
- 조회수와 계정의 비교 게시물 목록
- 광고·공동 게시·고정 게시 여부와 확인할 수 없는 항목
- 자신의 계정일 때만 제공된 도달·저장·공유·팔로우·시청 지속 자료

첫 문구의 짧은 인용과 전체 대본 복제를 구분한다. 재사용 허락과 출처 표시를 같은 것으로 취급하지 않는다. 법적 판단이 필요한 질문은 관련 공식 근거를 확인한다.

## 수치 비교

- 영상 조회수 / 비교 집합 조회수 중앙값은 '평소 대비 배수'다. 비교 집합의 기간·게시 후 경과 시간·표본 수를 함께 제시한다. 중앙값이 0이거나 자료가 없으면 계산하지 않는다.
- 조회수가 잘된 게시물만 골라 기준 중앙값을 계산하지 않는다. 광고·공동 게시·특이한 이벤트는 비교를 분리하거나 교란 요인으로 표시한다.
- 공유 / 도달, 팔로우 / 도달은 각 분모가 있을 때만 계산한다. 조회수를 도달로 바꿔 넣지 않는다. 공유 전체와 DM 전송을 구분할 수 없으면 같은 지표라고 하지 않는다.
- 시청 지속 수치가 없으면 훅 성능을 직접 측정했다고 하지 않는다. 타 계정의 수익·전환·저장·시청 지속은 공개 조회수에서 역산하지 않는다.
- 낮은 조회수=훅 실패, 낮은 팔로우 전환=프로필 실패로 단정하지 않는다. 주제, 타깃 적합성, 노출 표본, 영상과 프로필의 연결, 계정 상태 등을 가능한 설명으로 다룬다.
- 3배, 30개 등 임의의 문턱을 통계적 검증처럼 제시하지 않는다. 적은 표본은 탐색용이며 많은 표본도 인과를 증명하지 않는다.

## 결과 형식

1. 관찰: 확인된 패턴, 자료 범위, 반례.
2. 해석: 가능한 설명과 불확실성.
3. 다음 실험: 바꿀 요소 하나, 유지할 요소, 확인할 지표.

플랫폼 간 수치 정의가 다르거나 노출 환경이 다르면 직접 우열을 정하지 않는다. 본인의 이전 게시물과 비교하는 것이 가능한지 먼저 확인한다. 목표가 공감·참여이면 의미 있는 경험 답글도 함께 본다.
