# SNS 시작 전략 및 다음 작업 인계

정리일: 2026-10-23. 집에서 새 대화에 이 문서를 첨부하거나 읽도록 요청하면 이어서 논의할 수 있다.

이 문서는 대화 전문이 아니라 배경·선호·결정·제안·미해결 과제를 정리한 것이다. 사용자의 계획과 AI의 제안을 구분했으며, 외부 계정 수치는 당시 확인한 자료로 현재값을 보장하지 않는다.

## 1. 사용자의 배경과 일정

- 개발 경력 총 9년. 약 8년은 게임 서버 개발, 최근 약 1년은 AI 웹서비스 풀스택 개발.
- 10월 30일 퇴사 예정.
- 아내는 19일 일본으로 출국해 새 직장에 입사.
- 11월 30일까지 수도권 거주, 12월부터 포항 본가 거주 예정.
- 내년 3~4월까지 강아지와 함께 아내가 있는 일본으로 이동할 계획.
- 위 상대 날짜는 현재 대화 기준으로 2026년 10~12월, 2027년 3~4월로 해석했다. 실행 전 실제 일정 확인 필요.
- 운동과 일본어 공부는 SNS 성과와 별개로 원래 하려던 활동이다.
- 빠른 수익화에 관심이 있지만, 전략이 복잡해져 시작을 미루게 되는 상황은 피하고 싶어 한다.

## 2. 사용자가 정한 방향과 아직 제안 단계인 내용

- 먼저 숏폼 제작을 시작한다. 블로그는 뒤로 미룬다.
- 주제는 운동, 일본어 공부, 일본행 준비와 생활이다.

## 3. 브랜딩의 중심

> 9년 차 개발자, 일본에 있는 아내와 합류하기 전까지 몸과 일본어를 준비하는 기록.

일본행은 이야기의 배경이고, 더 넓은 공감 지점은 “해야 하는데 미루던 일을 다시 시작하는 사람”이다.

- 운동을 아주 잘하는 사람처럼 꾸밀 필요는 없다.
- 직접 겪은 귀찮음, 불안, 실패, 복귀, 작은 변화를 보여준다.
- 공감은 실제 어려움에서, 도전 의욕은 확인 가능한 작은 변화에서 만들어보자는 기획 가설이다. 성과가 검증된 공식은 아니다.
- 일본어·운동·일본행을 별개 정보 채널로 벌리기보다 한 사람의 생활 변화로 연결한다.
- ‘생존’이라는 큰 표현을 강요하기보다 구체적인 실제 상황으로 말한다.
- 일본에 간 뒤에는 준비 당시 기대와 실제 경험을 비교하는 콘텐츠로 이어갈 수 있다.

첫 소개 대본 후보:

> 9년 동안 개발자로 일했습니다.
> 일본에 있는 아내에게 가기 전까지,
> 미뤄둔 운동과 일본어를 다시 시작합니다.
> 일단 30일, 얼마나 달라질까요?

이 문장은 제안이다. 본인이 실제로 느끼는 말투로 수정해야 한다.

| 구간 | 기록할 내용 |
| --- | --- |
| 시작 | 현재 가능한 동작과 수준, 시작하는 이유 |
| 첫 주 | 운동할 공간, 시작하기 어려운 순간, 실제 실행 |
| 중간 | 처음과 비슷한 조건으로 비교, 쉬거나 실패한 날의 복귀 |
| 마지막 | 달라진 점과 그대로인 점, 12월 헬스장으로 이어지는 계획 |

- 30일 챌린지와 매일 같은 운동을 하는 규칙을 구분한다. 쉬는 날도 기록에 포함 가능.
- 몸의 극적 변화나 정해진 성과를 약속하지 않는다.
- 푸시업을 대표 장면으로 삼는 것과 실제 운동 프로그램을 푸시업만으로 구성하는 것은 다르다.
- 구체적인 횟수·세트·빈도는 아직 정하지 않았다. 현재 푸시업 능력, 운동 경력, 손목·어깨 불편함 여부도 답변받지 않았다.
- 다음 논의에서는 촬영 가능한 환경과 실제 운동 수준부터 확인한다.

## 6. 플랫폼별 운영

### 릴스·유튜브 쇼츠·틱톡

처음에는 워터마크 없는 공통 세로 원본 한 편을 만들어 각각 업로드한다는 제안.

- 본편은 공유하고 첫 장면, 제목, 설명, 자막 위치부터 필요에 따라 조정.
- 틱톡이라고 무조건 빠른 컷·유행 음악을 넣어야 한다고 단정하지 않는다.
- 각 플랫폼의 화면 요소가 자막을 가리는지 실제 업로드 화면에서 확인.
- 음악은 각 플랫폼에서 사용 가능한 범위를 확인. 한 플랫폼에서 넣은 음악을 그대로 옮겨 쓸 수 있다고 가정하지 않는다.
- 다른 플랫폼의 조회수 차이만으로 편집의 효과를 입증했다고 하지 않는다.

시작 문구 실험 예시:

- A: “일본 가기 전, 운동 습관 만들기 Day 1.”
- B: “12월부터 운동하려다가, 오늘 시작한 이유.”

플랫폼별 정답이 아니라 시험할 후보이다.

### 스레드

운동과 공부를 하면서 생긴 생각을 독립적인 글로 남긴다. 영상 공지만 올리는 계정으로 만들 필요는 없다.

소재 예시 — 실제 경험과 맞을 때 사용:

> 12월에 이사하면 헬스장 가려고 했다. 생각해보니 운동 시작 날짜를 자꾸 이사 날짜에 맞추고 있었다. 오늘은 그냥 집에서 시작해보려고.

> 개발 공부는 막히면 검색하면서 몇 시간씩 하는데, 일본어는 못 알아듣는 순간 끄고 싶어진다. 다시 초보자가 되는 게 생각보다 어렵다.

> 같은 일본어 기사를 며칠째 듣는 중. 오늘 처음으로 자막 보기 전에 들린 문장이 있었다.

- 매번 교훈이나 질문으로 마무리할 필요는 없다.
- 정말 궁금한 경험을 묻고, 답글에는 대화를 이어간다.
- 영상에는 장면, 스레드에는 생각을 남기는 운영 방식.
- Meta는 답글과 스레드용 독자적 콘텐츠의 중요성을 안내하지만, 개인 계정 성장의 보장으로 해석하지 않는다.

### 잠정 운영량과 확인 지표

- 영상 주 2편: 며칠 기록을 묶어 3개 플랫폼에 게시.
- 스레드 주 3편 정도: 실제 기록에서 소재 추출.
- 주 1회 확인: 제공되는 시청 지속·완주·팔로우 반응과 경험을 나누는 답글.
- 이 빈도는 제안이며, 운동·공부를 해칠 정도로 촬영과 편집이 커지면 줄인다.
- 롱폼 시작 시점은 미정.

검토 대상: https://github.com/Jakeschincariol/instagram-agent-skill

- 검토한 로컬 소스 커밋: `d03c56b`.
- 13개 스킬로 구성된 기획·대본·프로필·게시 후 분석 도구.
- 무료 MIT 라이선스. AI 서비스 사용 비용은 별도.
- 자체 Instagram 로그인·게시·영상 편집·수익 조회 기능은 없음.
- `voice.md`로 본인의 말투와 실제 경험을 공유하는 구조가 유용.
- 참고 영상 조회수를 해당 계정의 최근 중앙값과 비교하는 접근도 유용하나, 경과 시간·광고 여부·표본 편향을 함께 다뤄야 함.

직접 확인한 문제:

- `hookscore.py`에 “운동을 계속 미루다가 오늘 처음 시작했습니다.” 입력 시 단어 수 0, 발화 0초, 빈 문장 판정, 8.4점으로 출력.
- 영어 중심 정규식 때문에 한국어·일본어의 점수와 시간 추정은 그대로 사용할 수 없음.
- 제작자의 README 보고상 성공/부진 영상 구별 성능은 AUC 0.56. 독립 재현은 하지 않았고 흥행 예측 도구로 볼 수 없음.
- `ig-audit`의 ‘낮은 조회수는 훅 문제’ 같은 단정은 가설로 완화해야 함.
- 한국어로 번역만 하는 것보다 평가 방식과 실제 운영 흐름을 재설계하는 편이 적절함.

사용자 제안: 원본을 분석하고 한국인이 쓰기 좋은 인스타 에이전트 스킬로 수정하면 되지 않느냐.

이에 따라 아래 첫 버전을 작성했다.

- [원본 MIT 고지](skills/instagram-ko/LICENSE)

현재 포함한 기능:

- 한국어 포지셔닝·훅·촬영 대본 작성 지침.
- 영어 점수 대신 상황 이해·궁금증·실제 근거·화면 구성 평가.
- 한국어 발화 길이는 실제 낭독으로 확인하도록 명시.
- 관찰과 해석을 구분하는 계정·성과 분석.
- Threads 글과 TikTok·Shorts 버전으로 같은 소재를 활용하는 방식.
- 타 크리에이터에게도 사용할 수 있도록 개인 상황을 스킬 기본값에 넣지 않음.

검증 및 배포 상태:

- `quick_validate.py` 형식 검증 통과.
- 아직 실제 30일 운영이나 사용자 테스트를 통한 효과 검증은 하지 않음.
- 자동 분석 스크립트, 편집 도구, 수집 API는 구현하지 않음.
- 작업 폴더에 초안으로 저장했으며 전역 설치, Git 커밋, GitHub 업로드, 공개 배포는 하지 않음.
- 첫 사용 사례로 본인의 챌린지를 적용하고 불편한 부분을 개선한다는 방향을 제안했음.

## 11. 다음에 할 일 — 우선순위 제안

### 먼저 첫 영상을 구체화

1. 현재 운동 능력·불편함·홈트 공간·장비 확인.
2. 첫 30일의 실제 목표를 정함. 운동 수행 목표와 콘텐츠 게시 목표는 분리.
3. 첫 영상의 훅 후보 2~3개와 실제 촬영 가능한 장면 구성.
4. Shuru 캡처를 쓸 경우 해당 장면과 사용 범위를 정해 허락 요청.
5. 공통 원본 한 편과 스레드 글 1개를 만들고 제작 부담 확인.

### 스킬은 실제 제작에 쓰며 다듬기

1. 개인 말투 양식을 지금까지의 정보로 채우되 미확인 사항은 표시.
2. 첫 대본을 읽어보고 번역투·발화 길이·불필요한 설명 수정.
3. 한국어 훅 자동 점수는 서둘러 구현하지 않음. 필요하다면 충분한 한국어 자료와 검증 기준부터 설계.
4. 실제 게시물의 지표가 쌓이면 분석 지침이 유효한지 검토.

## 12. 미해결·보류한 주제

- 계정명, 프로필 최종 문구, 얼굴·목소리 노출 방식.
- 운동과 일본어의 비중, 한 계정 또는 계정 분리 최종 결정.
- 구체적인 운동 루틴과 현재 체력.
- HyperFrames로 촬영 영상 편집 가능한지: 이 문서에 포함할 검증 결과 없음.
- 롱폼 시작 시점.
- Naver·Ameba·개인 기술 블로그: 우선순위 뒤로 미룸.
- 수익화: 실제 성과·타깃이 생긴 뒤 구체화 필요. 확인된 수익 모델이나 예상 수입은 아직 없음.
- Instagram 수익 추정 플랫폼 탐색 중 사용자는 Grum은 안 된다고 밝혔음.
- Ascefire77의 정확한 계정과 실제 영상 분석.
- 한국어 스킬의 이름, 배포 방식, Codex/Claude 등 설치 대상.
